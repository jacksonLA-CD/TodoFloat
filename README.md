# TodoFloat

一个 macOS 菜单栏待办小工具：按 **⌘ ⇧ Space** 呼出悬浮窗，在里面输入和查看待办。

## 安装

需要 macOS 13 及以上版本，以及 Swift（装好 Xcode 命令行工具即可）。

```bash
./build.sh --install
```

运行后会编译、安装到 `~/Applications/TodoFloat.app` 并启动。修改代码后重新运行这条命令即可更新。

## 使用

**基本操作**

- **⌘ ⇧ Space**：打开或关闭悬浮窗
- 输入文字后按 **回车**：添加待办
- 点击左边的圆圈：标记完成或取消完成
- 双击某一条的文字：编辑
- 鼠标移到某一条上，点击右边的垃圾桶，或者右键：删除
- 底部的 **清除已完成**：点一次会变成“确认”，3 秒内再点一次才会清除
- **Esc**，或点击窗口外面：关闭悬浮窗

**截止日期和优先级**

添加或编辑时，在文字后面加上标记（要用空格隔开，全角的 ＠ ！ 也可以）：

| 标记 | 意思 |
|---|---|
| `!` / `!!` / `!!!` | 低 / 中 / 高优先级 |
| `@今天` `@明天` `@后天` | 截止日期 |
| `@周五` `@下周一` | 本周或下周的某一天（`@周五` 指今天或之后最近的周五） |
| `@10-20` `@10/20` `@10月20日` | 某月某日；没写年份时用今年，已经过去的就算明年 |
| `@2027-1-3` | 带年份的日期 |
| `@3天后` `@+3` | 几天以后 |
| `@明天15:00` `@明天 15:00` | 精确到时间：时间可以直接接在日期后面，也可以空一格 |
| `@周五下午3点` `@10-20 9:30` | 也支持 `15点`、`15点30分`、`3点半`、`上午/中午/下午/晚上/凌晨`、`3pm`、全角冒号 `15：00` |
| `@15:00` `@晚上9点` | 只写时间：今天这个时间，如果已经过了就是明天 |

例如 `交周报 @周五 !!`、`开会 @明天 14:30 !!!`。没有 @ 的时间（如 `会议 15:00`）不会被识别，会保留在文字里。输入时，输入框下面会显示识别出来的截止日期和优先级。编辑某一条时，标记会显示在文字后面，删掉标记就是清除。也可以右键设置优先级和截止日期（右键菜单只能选日期，要精确到时间请按回车编辑）。

列表里，优先级用红 / 橙 / 蓝色小旗表示高 / 中 / 低；截止时间显示在右边（如“明天 15:00”），已过期是红色，今天到期是橙色。带时间的过了那个时刻就算过期，只有日期的到当天结束才算过期。

未完成的待办先按优先级排（高在前），优先级相同时按截止时间排（早的在前；只有日期的算当天结束；没有截止的在后），再相同就是新添加的在前。

**键盘操作**

| 按键 | 作用 |
|---|---|
| ↓ / ↑ | 在列表里上下选择；从第一条再按 ↑ 回到输入框 |
| 空格 | 标记选中的一条为完成或未完成 |
| 回车 | 编辑选中的一条（编辑时回车保存，Esc 取消） |
| 1 / 2 / 3 / 0 | 把选中的一条设为高 / 中 / 低 / 无优先级 |
| ⌘ ⌫ | 删除选中的一条 |
| Esc | 关闭悬浮窗 |

使用中文输入法打字时，方向键、回车、Esc 会先交给输入法处理，不会误触这些操作。

**菜单栏图标**

- 打开待办
- 在访达中显示数据文件
- 开机自动启动：勾选后登录时自动运行。第一次开启时，如果系统要求确认，会自动打开“系统设置 > 通用 > 登录项”。
- 退出

## 数据

待办保存在 `~/Library/Application Support/TodoFloat/todos.json`。如果文件损坏、无法读取，会先把它备份成 `todos.corrupt-<时间戳>.json`，不会覆盖原文件。

## 项目结构

```
Sources/TodoFloat/
  main.swift            应用入口
  AppDelegate.swift     菜单栏图标、注册快捷键
  HotKey.swift          全局快捷键（Carbon，不需要辅助功能权限）
  FloatingPanel.swift   悬浮窗
  TodoView.swift        悬浮窗界面（SwiftUI）
  TodoListModel.swift   列表选中、编辑状态和键盘操作
  TodoStore.swift       待办数据和 JSON 存储
  QuickEntry.swift      @日期/时间 和 ! 优先级的解析与显示
Resources/Info.plist    应用信息（LSUIElement：不在 Dock 显示）
build.sh                打包和安装脚本
```
